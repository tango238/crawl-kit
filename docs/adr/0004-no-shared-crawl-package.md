# ADR-0004: 共有クロールパッケージを作らない

- **status**: accepted
- **date**: 2026-06-27
- **affects**: （behavior 層）

## Context
当初、rdra と loop-e2e が両方クロールするため、共有クロール機構を独立パッケージへ抜く案が
あった。しかし ADR-0003 で rdra が構造専任になり、クロールを持たなくなった。

## Decision
共有クロールパッケージを作らない。クロール/シナリオ機構は behavior(loop-e2e)の内部にのみ住む。

## Consequences
- 共有相手が存在しないため、抜くべき重複が最初から無い。パッケージを一つ丸ごと削れる(簡素化)。
- 「v1 で重複を許すか今抜くか」という問い自体が消滅する。

## Alternatives considered
- 空の共有パッケージを用意: 使われない抽象を増やすだけ。退けた。
- behavior 内で `src/crawl/` をモジュールとして切るのは可(パッケージ境界にはしない)。
